# Python Practice Portfolio 🐍

โปรเจกต์นี้เป็นการรวบรวมโค้ดและแบบฝึกหัดสำหรับพัฒนาทักษะภาษา Python โดยแบ่งเนื้อหาจากการปูพื้นฐานไปจนถึงการสร้างมินิโปรเจกต์

## 📁 โครงสร้างการเรียนรู้ (Learning Path)
- [ ] **01-basics:** พื้นฐานการเขียนโปรแกรม (ตัวแปร, ลูป, เงื่อนไข)
- [ ] **02-data-structures:** โครงสร้างข้อมูล (List, Dictionary, Set)
- [ ] **03-oop:** การเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming)
- [ ] **04-mini-projects:** โปรเจกต์ขนาดเล็กที่ประยุกต์ใช้ความรู้ทั้งหมด
